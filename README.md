## (النص العربي في الاسفل)

A lightweight word processor built with **PySide6 (Qt6)**.  
A simple alternative to LibreOffice Writer and Microsoft Word.  
Saves documents in `ktb`, `odt`, `html`, `md` and `txt` formats and exports to PDF.

---

## Dependencies

### Debian/Ubuntu Linux

```bash
sudo apt install --no-install-recommends git python3-pyside6 nodejs
git clone https://github.com/abdulrahman-103/Kitab
cd Kitab
python main.py
```

### Arch Linux

```bash
sudo pacman -Syu git pyside6 nodejs
git clone https://github.com/abdulrahman-103/Kitab
cd Kitab
python main.py
```

###  Fedora Linux

```bash
sudo dnf install --setopt=install_weak_deps=False git python3-pyside6 nodejs22
git clone https://github.com/abdulrahman-103/Kitab
cd Kitab
python main.py
```

### Other platforms
Install git, pyside6 and nodejs
```bash
git clone https://github.com/abdulrahman-103/Kitab
cd Kitab
python main.py
```
